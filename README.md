# Journi-Sphere

**Journi-Sphere** is a mobile application built with **React Native Expo** designed to revolutionize the way tourists plan and experience trips. By leveraging **AI technology**, the app generates personalized trip itineraries and provides end-to-end travel solutions, including hotel and car rental bookings, ensuring users can organize their trips efficiently and seamlessly.

## Features

1. **Tourist Spot Guides**

   * Provides detailed information about tourist spots, including their **historical significance**.
   * Users can explore places with enriched context for a meaningful travel experience.

2. **Reviews**

   * Displays both **Google reviews** and **user-submitted reviews** for tourist spots, hotels, and car rentals.
   * Helps users make informed decisions about their travel choices.

3. **AI-Powered Trip Itineraries**

   * Generates personalized **trip plans** based on user preferences using an AI model.
   * Suggests optimized travel routes and highlights must-visit locations.

4. **Data Scraping & AI Extraction**

   * Scrapes relevant data about tourist spots from trusted sources.
   * Extracts key details using AI to provide accurate, up-to-date information.

5. **Google Maps Integration & Navigation**

   * Integrates with **Google Maps API** for real-time navigation and directions.
   * Auto-detects user location for seamless travel planning.

6. **Hotels & Car Rentals Integration**

   * Lists hotels and car rental services available at the travel destination.
   * Includes booking functionality for both hotels and cars.

7. **Payment Gateway Integration**

   * Allows users to **securely pay** for bookings directly within the app.

8. **End-to-End Trip Management**

   * Combines itinerary generation, accommodation, and transport in a single platform.
   * Optimized for convenience and a smooth user experience.

## Installation

### Prerequisites

* Node.js (v16 or above)
* npm or yarn
* Expo CLI
* Android Studio / Xcode (for mobile simulation)

### Steps

1. Clone the repository:

```bash
git clone https://github.com/yourusername/journi-sphere.git
cd journi-sphere
```

2. Install dependencies:

```bash
npm install
# or
yarn install
```

3. Start the Expo development server:

```bash
expo start
```

4. Run on your mobile device or simulator using the Expo Go app.

## Usage

1. Open the app and **allow location access** for auto-detection.
2. Browse **tourist spots** and explore their historical details.
3. Generate a **personalized AI-based itinerary** for your trip.
4. Browse and **book hotels or car rentals** directly.
5. View **reviews** and ratings to help in decision-making.
6. Pay securely via the integrated **payment gateway**.
